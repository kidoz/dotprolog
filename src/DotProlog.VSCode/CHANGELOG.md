# Changelog

## 1.0.0

- Release the extension on the Marketplace stable channel with no preview or pre-release flags.
- Include Prolog and contract syntax highlighting, snippets and language configuration.
- Bundle the DotProlog language server for live diagnostics, completion, hover, Outline,
  definitions, references and conservative predicate rename.
- Support explicit project selection, language modes, workspace trust and server recovery.
- Provide a universal managed package and native packages for Linux x64, Windows x64 and macOS arm64.
- Keep the documented limitations: no formatting, debugging, query execution or contract diagnostics;
  one selected project per window; browser-only and virtual workspaces are unsupported.
- Add the DotProlog extension icon and Marketplace listing assets.
