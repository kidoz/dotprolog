# Changelog

## 0.1.0 (preview)

- Add Prolog and contract syntax highlighting, snippets and language configuration.
- Bundle the DotProlog language server for live diagnostics, completion, hover, Outline,
  definitions, references and conservative predicate rename.
- Support explicit project selection, language modes, workspace trust and server recovery.
- Provide a managed package and native packages for Linux x64, Windows x64 and macOS arm64.
- Add the DotProlog extension icon and Marketplace listing assets.
